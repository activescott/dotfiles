When Scott asks a "why/what/can we" question, answer it plainly in prose before (or instead of) running more commands. He interrupted mid-investigation with "pls answer my questions with answers, and not more commands."

**Why:** Questions are requests for understanding, not task assignments; command-first responses read as evasion.

**How to apply:** Explain the concept/mechanism first with what's already known; run verification commands only after, or when the answer genuinely requires new data — and say why.
